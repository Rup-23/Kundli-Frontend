## Testing Notice

> **Note:** This project is intended for testing purposes only.

The current implementation works only for the date format:

```text
01-01-<any-year>
```

For example:

* `01-01-2023`
* `01-01-2024`
* `01-01-2025`

This limitation exists because the API used in this project requires a paid subscription to access data for all dates and complete historical details. Since the free plan has restricted access, only the above date format is supported for testing.
